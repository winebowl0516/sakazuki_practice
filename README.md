# 歆羽｜數學練習室

台灣 108 課綱數學練習網站的第一版互動原型。無需安裝套件，直接用瀏覽器開啟 `index.html` 即可操作。

## 原型流程

1. 選擇國小、國中或高中，設定年級；高中可選數學 A 或數學 B。
2. 依學期瀏覽教材章節，整章勾選或展開小節自主選擇。
3. 設定題數、難度與作答時間，建立練習卷。
4. 作答時可切換「劃掉選項」模式，用刪除線標記不可能的答案；標記不會當成作答，交卷後可查看分數與正確答案。已補詳解的題目可查看解題步驟，待補題會清楚標示。

## 課程與題庫說明

課程範圍參照[國家教育研究院十二年國教課程綱要](https://www.naer.edu.tw/PageSyllabus?fid=52)中的[數學領域課程綱要 PDF](https://www.naer.edu.tw/upload/1/16/doc/815/%E5%8D%81%E4%BA%8C%E5%B9%B4%E5%9C%8B%E6%B0%91%E5%9F%BA%E6%9C%AC%E6%95%99%E8%82%B2%E8%AA%B2%E7%A8%8B%E7%B6%B1%E8%A6%81%E5%9C%8B%E6%B0%91%E4%B8%AD%E5%B0%8F%E5%AD%B8%E6%9A%A8%E6%99%AE%E9%80%9A%E5%9E%8B%E9%AB%98%E7%B4%9A%E4%B8%AD%E7%AD%89%E5%AD%B8%E6%A0%A1-%E6%95%B8%E5%AD%B8%E9%A0%98%E5%9F%9F.pdf)，並整理成台灣常見的「冊別／學期 → 章 → 小節」選擇方式。改變年級會更新章節清單；高一顯示共同必修，高二、高三可選數學 A／B 查看各自課程。各出版社的章名、順序及分冊方式會有差異，原型目前採共通編排，尚未逐一對應出版社版本。

目前題庫包含原有示範題與歷屆試題、高一上下新題，以及國一、國二、國三各 600 道原創題。國中七至九年級各有 12 個小節，每個小節各 50 題。國一涵蓋正負數與數線、整數及分數運算、指數與科學記號、代數式與一元一次方程式、比例、幾何與角度、統計圖表及資料判讀；國二涵蓋乘法公式、多項式與因式分解、聯立方程式、坐標與一次函數、三角形與四邊形、幾何推理、尺規作圖及統計；國三涵蓋相似形、圓、三角比、二次函數與方程式，以及機率與統計。高一上下各有六個小節，每個小節新增 50 題；加上原有題目後，各小節目前有 51 至 52 題。新題已附答案，詳解待補。歷屆題目保留年份、題號、官方試題及答案連結。題庫仍在擴充，其他年級與小節可能顯示「題庫建置中」；若所選範圍的題目少於設定題數，練習卷會依現有題目出題。

國一至國三題目依解題步驟與推理需求分為基礎、標準、挑戰三級：基礎以概念辨認或單步計算為主，標準需要套用公式、整合步驟或解讀題意，挑戰著重多步驟推理、建模或概念應用。難度選單的「標準」目前適用國中題庫；其他學段暫沿用原有分類。題庫已調整重複題與部分題目條件，並修正國二代數題的選項及尺規作圖題的條件敘述。

題目來源包含原創練習與公開歷屆試題。會考歷屆試題可在[國中教育會考官方歷屆試題頁](https://cap.rcpet.edu.tw/examination.html)查閱，試題答案亦連至官方參考答案。每題保存學段、年級、課程、對應小節、難度、答案、詳解欄位與來源；待補詳解的題目會在交卷頁標示。

高一上新增的 300 題及答案另以 JSON Lines 格式保存在[高一上待補詳解題庫.txt](高一上待補詳解題庫.txt)；高一下題目則在[高一下待補詳解題庫.txt](高一下待補詳解題庫.txt)。兩個檔案首行皆說明資料欄位，後續每行是一題；可交給未來的 AI 補寫 `explanation` 欄位。
